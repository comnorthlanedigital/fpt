# Mint Dark Starter (Shopify Online Store 2.0 theme, Liquid)
Upload `zips/mint-dark-shopify-theme.zip` in Shopify admin > Online Store > Themes > Add theme > Upload zip file.
- Colors, fonts, radius: Theme settings (defaults: #090909 background, #63F9AB accent).
- Sections: announcement bar (optional real end-time countdown), header, hero, best sellers, image gallery, benefits, reviews, FAQ, call to action, newsletter, footer.
- Templates: home, product, collection, collections list, cart, page, blog, article, search, 404.
- All copy and image slots are placeholders. Only add facts, reviews and offers that are real for the store.
- Not included yet: customer account templates, password page, cart drawer, product variant swatches.
- Not verified in a live Shopify store; run `shopify theme check` before publishing.
